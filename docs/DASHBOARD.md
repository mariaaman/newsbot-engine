# NewsBot Control: ড্যাশবোর্ড

ফোন থেকে পুরো বট দেখা ও বদলানোর জায়গা। এটা একটা Cloudflare Worker (ফ্রি প্ল্যানে চলে)। ডাটাবেস নেই: brain রিপোই আসল তথ্যের উৎস, তাই প্রতিটি বদলানো GitHub-এ একটা commit হয় (ইতিহাস ও আগের সংস্করণ ফিরিয়ে আনা সহ)।

## কী কী আছে

| ট্যাব | কাজ |
|---|---|
| 🏠 হোম | সাইট চালু কি না, মোড (review/auto) ও এক-ট্যাপে বদল, আর্টিকেল ও খসড়ার সংখ্যা, শেষ hourly রান, আজকের মডেল-ব্যবহার, অনুপস্থিত সিক্রেট, "এখনই চালান" |
| 📝 খসড়া | সংবেদনশীল ও আটকে থাকা খসড়া: পড়া, শিরোনাম/সারাংশ/লেখা ঠিক করা, সংরক্ষণ, অনুমোদন ও প্রকাশ, বাতিল |
| 📰 আর্টিকেল | প্রকাশিত লেখা সম্পাদনা, সাইট থেকে লুকানো/আবার দেখানো |
| ⚙️ সেটিংস | ~৯০টি সেটিং (সীমা, স্কোরিং, মান-যাচাই, বিজ্ঞাপন, টেলিগ্রাম...), মডেল চেইন (মডেল আইডি বদল, যোগ, সরানো), দৈনিক টোকেন/রিকোয়েস্ট সীমা, কাজ → স্তর, এমবেডিং, কাঁচা ফাইল (সব `config/*.yaml`, `prompts/*.md`), ইতিহাস ও ফিরিয়ে আনা |

| ☰ আরও | খোলা PR merge/বন্ধ, ২-ধাপ লগইন, সব ডিভাইস থেকে লগআউট, কার্যকলাপের লগ |

## সেটআপ (একবার, ফোন থেকেই হয়)

**১. Cloudflare টোকেনে অনুমতি যোগ।** Cloudflare, Manage Account, Account API Tokens, আপনার টোকেনের **Edit**। Permissions-এ থাকতে হবে: **Account, Workers Scripts, Edit** (setup-approve-এর জন্য আগেই দিয়েছেন) এবং নতুন: **Account, Workers KV Storage, Edit**। Save।

**২. GitHub টোকেন (ড্যাশবোর্ডের জন্য আলাদা)।** GitHub, Settings, Developer settings, Fine-grained tokens, Generate। Repository access: `newsbot-brain` ও `newsbot-engine`। Permissions: **Contents, Actions, Secrets, Variables, Pull requests**: সবকটায় Read and write (Metadata: Read-only নিজে থেকে থাকে)। কপি করে engine রিপোর Settings, Secrets and variables, Actions-এ নাম **`DASHBOARD_GH_TOKEN`** দিয়ে রাখুন।

**৩. পাসওয়ার্ড।** নিজে একটা লম্বা পাসওয়ার্ড বানান (**কমপক্ষে ১৪ অক্ষর**, তিন-চারটা শব্দ জোড়া দিলেই চলে)। একই জায়গায় সিক্রেট **`DASHBOARD_PASSWORD`** নামে রাখুন।

**৪. চালান।** engine রিপোর Actions, **setup-dashboard**, Run workflow। প্রথমে ড্যাশবোর্ডের টেস্ট চলে, তারপর Worker তৈরি, KV তৈরি, সিক্রেট বসানো ও যাচাই। শেষে টেলিগ্রামে ঠিকানা আসবে। লগ পাবলিক, তাই সেখানে ঠিকানা বা সিক্রেট দেখায় না, শুধু `ok` বা `fail:কারণ`।

প্রথম লগইনের পর **আরও, ২-ধাপ চালু করুন** (Google Authenticator বা অনুরূপ অ্যাপ)। ব্রাউজারের মেনু থেকে "হোম স্ক্রিনে যোগ করুন" দিলে অ্যাপের মতো খোলে।

setup-dashboard যতবার চালাবেন, নতুন সেশন-সিক্রেট বসে: সবাই লগআউট হয়, আর ২-ধাপও রিসেট হয় (অথেনটিকেটর হারালে এটাই উদ্ধারের পথ)।

## নিরাপত্তা: কী আছে, কী নেই

- **লগইন:** লম্বা পাসওয়ার্ড (+ ঐচ্ছিক ২-ধাপ কোড, একই কোড দ্বিতীয়বার চলে না)। একই ঠিকানা থেকে ৫ বার ভুল হলে ১৫ মিনিট বন্ধ। সেশন ১২ ঘণ্টার, `HttpOnly`, `Secure`, `SameSite=Strict` কুকি।
- **অন্য সাইট থেকে আক্রমণ:** পরিবর্তনের প্রতিটি অনুরোধে বিশেষ হেডার ও একই-origin যাচাই। কড়া CSP: শুধু নিজের ফাইল থেকে স্ক্রিপ্ট চলে।
- **সিক্রেট:** ড্যাশবোর্ড কোনো সিক্রেটের মান পড়তে বা দেখাতে পারে না, শুধু লিখতে পারে। লেখার আগে GitHub-এর পাবলিক কী দিয়ে এনক্রিপ্ট হয় (libsodium sealed box, আসল libsodium দিয়ে যাচাই করা)। কার্যকলাপের লগে শুধু নাম থাকে, মান নয়।
- **সীমাবদ্ধ কাজ:** শুধু তালিকাভুক্ত workflow চালানো যায়, শুধু `config/*.yaml` ও `prompts/*.md` সম্পাদনা করা যায়, সেটিং বদল স্কিমা দিয়ে যাচাই হয় (ইঞ্জিনের নিজের সীমার সঙ্গে স্বয়ংক্রিয় টেস্টে মেলানো)।
- **ঝুঁকি যা থেকে যায়:** ড্যাশবোর্ডের GitHub টোকেন শক্তিশালী (brain-এ লিখতে পারে, workflow চালাতে পারে, সিক্রেট বদলাতে পারে)। কেউ পাসওয়ার্ড (ও ২-ধাপ চালু থাকলে কোড) পেলে এগুলো পায়। তাই পাসওয়ার্ড অন্য কোথাও ব্যবহার করবেন না। আরও কড়া চাইলে Cloudflare Access (Zero Trust, ফ্রি) Worker-এর সামনে বসাতে পারেন। আমি এটা ডিফল্টে রাখিনি, কারণ ফ্রি প্ল্যানের শর্ত (যেমন কার্ড চায় কি না) অ্যাকাউন্টভেদে আলাদা হতে পারে।

## সীমা ও জানা কথা

- **ফ্রি Worker:** দিনে ১,০০,০০০ অনুরোধ, প্রতি অনুরোধে ১০ মিলিসেকেন্ড CPU। এই ড্যাশবোর্ড হালকা (সেটিংস পাতায় আসল কনফিগে প্রায় ৩ ms), তবে কখনো Cloudflare-এর error 1102 দেখলে বলুন, আমি আরও ছোট করব (বা $৫-এর প্ল্যানে গেলে সীমা অনেক বাড়ে)।
- **তালিকা:** খসড়া ও আর্টিকেলের তালিকা নামের ক্রমে, পাতায় ১৫টা। তারিখ ধরে সাজানো নেই, খোঁজার ঘরে নামের অংশ লিখে খুঁজুন।
- **লুকানো ≠ মোছা:** ‘সাইট থেকে লুকান’ লেখাটার ফ্রন্ট ম্যাটারে `draft: true` বসায়; Hugo পাতাটা বানায় না। ফাইল `content/`-এ থাকে বলে ইঞ্জিনের হিসাব (প্রকাশিত স্টোরি) ঠিক থাকে। ফাইল মুছে ফেললে ইঞ্জিন বিভ্রান্ত হতে পারত, তাই মোছার বাটন রাখিনি।
- **ভুল সেটিং:** প্রতি সংরক্ষণের পর `validate-config` চলে। লাল হলে (রান ট্যাবে দেখুন) সেটিংস, ফাইল অংশ থেকে আগের সংস্করণ ফিরিয়ে আনুন। ইঞ্জিনও প্রতি রানের শুরুতে কনফিগ যাচাই করে, ভুল থাকলে কিছু প্রকাশ করে না।
- **টেলিগ্রাম টোকেন/চ্যাট আইডি বদলালে** ‘কী’ পাতায় সংরক্ষণের পর **setup-approve** চালান, যাতে অনুমোদন Worker নতুন মান পায়। Cloudflare টোকেন ড্যাশবোর্ড ধরে না, ইচ্ছা করে।
